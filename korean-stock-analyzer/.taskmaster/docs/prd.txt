# 프로젝트 목적
현재 my-skill 폴더 내 마크다운(md) 가이드 문서 간의 명령어나 지시사항 충돌(Conflict)을 해결하고, 에이전트가 일관되게 동작할 수 있도록 문서들을 수정한다.

# 문제 상황 및 충돌 분석
1. 초기 Raw Data 파일명 명명 규칙 불일치
- GEMINI.md, 단계별 이용방법.md: `[기업명]_분석기초.md` 파일로 규정
- SKILL.md: `{날짜}_TrackA.md` 및 `TrackB.md`로 규정
- notebooklm_prompts.md: `기업명_기초분석`으로 규정

2. generate_html.py 스크립트 실행 경로 및 위치 불일치
- GEMINI.md: `3_Final_Reports` 폴더 안에 스크립트를 복사한 후 실행하라고 규정 (복사 필수)
- SKILL.md: `e:\antigravity-work\my-skill\korean-stock-analyzer\generate_html.py` 절대 경로에 있는 스크립트를 바로 실행하라고 규정

3. 데이터 입력 방식(UX) 충돌
- SKILL.md, notebooklm_prompts.md: 사용자가 채팅창에 텍스트를 복사/붙여넣기하면 에이전트가 파일을 생성하는 방식
- 단계별 이용방법.md: 사용자가 직접 `1_Raw_Data` 폴더에 마크다운 파일을 생성하고 저장한 뒤 에이전트에게 명령하는 방식

# 주요 기능 및 요구사항 (수정 사항)
- 파일명 규칙을 하나로 통일하여 모든 문서에 반영할 것.
- HTML 생성 스크립트 실행 방식을 결정(복사 방식 vs 절대 경로 호출 방식)하고 관련 문서 통일할 것.
- 데이터 입력 방식을 채팅창 입력 또는 직접 저장 중 하나로 결정하여 워크플로우 문서를 통일할 것.
