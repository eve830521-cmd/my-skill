  - 이에 따라 AI 생태계의 자금 조달 메커니즘이 '빅테크 자체 현금'에서 '월가 장기 민간자본(사모 크레딧, 연기금, 인프라 펀드)'과 '엔비디아 중심의 투자 플랫폼'으로 확장되는 금융시장화가 가속화되고 있음 `[팩트/전망: LS증권 9월]`.

### 테마 2: Agentic AI 확산과 메모리 아키텍처 재편 (대역폭 병목에서 용량·계층화 병목으로)
- **주요 동향**:
  - AI 기술이 단순 텍스트 답변 생성(Chatbot)을 넘어 목표 수립, Tool Calling, 코드 실행 및 다자간 협업을 수행하는 'Agentic AI'로 고도화되면서 서버 시스템의 메모리 요구 조건이 근본적으로 변화함 `[팩트/의견: LS증권 8월, 대신증권 8월]`.
  - 에이전트의 세션 유지와 긴 문맥 보관에 필요한 Key-Value(KV) Cache와 Agent State가 기하급수적으로 팽창함에 따라, 메모리 병목의 본질이 'HBM의 전송 대역폭(Bandwidth)'에서 '호스트 시스템의 메모리 용량(Capacity)' 및 '메모리 계층화(Memory Tiering)'로 이동하고 있음 `[팩트/전망: LS증권 8월]`.
- **핵심 수치 및 팩트**:
  - **Agentic AI Memory Footprint 급증**:
    - Task당 추론 호출 횟수(Inference Calls/Task): 2026E 75회 → 2028E 250회로 증가 `[전망: LS증권 8월]`.
    - 동시 실행 에이전트 수(Concurrent Agents): 2026E 4개 → 2027E 6개 → 2028E 8개로 확대 `[전망: LS증권 8월]`.
    - 동시 처리 KV Cache(Concurrent KV Cache): 2026E 160GB → 2027E 480GB → 2028E 1,000GB(1TB)로 6.25배 급증 `[전망: LS증권 8월]`.
    - 전체 에이전트 상태(Total Agent State): 2026E 500GB → 2027E 1,000GB → 2028E 2,000GB(2TB)로 4배 증가 `[전망: LS증권 8월]`.
    - 반면 HBM 용량은 2026E 192GB에서 2028E 576GB(3배) 증가에 그쳐, Total Agent State 대비 HBM 용량 배율이 2.6배에서 3.5배로 확대됨 `[팩트/전망: LS증권 8월]`.
  - **서버 CPU 아키텍처의 DRAM 채널 및 용량 확장**:
    - 서버 CPU 메모리 채널은 과거 8채널에서 최신 12채널(Intel Xeon 6 6900 계열), 차세대 16채널로 확장됨 `[팩트: LS증권 8월]`.
    - 12채널 2DPC 적용 시 소켓당 DIMM 장착 수는 최대 24개(2-소켓 서버 기준 48개)로 증가하며, 128GB DIMM 적용 시 CPU당 물리적 DRAM Capacity는 기존 0.5~1.0TB에서 3.0TB(2-소켓 서버 6.0TB), 16채널 시 4.0TB까지 확대됨 `[팩트: LS증권 8월]`.
  - **잠재 DRAM 수요충족률의 구조적 미달**:
    - 12채널 2DPC 128GB 기준 잠재 Capacity(3.0TB) 대비 실제 서버 CPU당 평균 DRAM 탑재량은 2025E 0.75TB(25%), 2026E 0.90TB(30%), 2027E 1.10TB(37%), 2028E 1.30TB(43%) 수준에 불과함 `[전망: LS증권 8월]`.
    - 이에 따라 서버 CPU 출하량 증가율이 2026E +14%에서 2027E +7%, 2028E +0%로 둔화되더라도, CPU당 메모리 Content 증가로 인해 Server DRAM Bit Demand는 2026E +37%, 2027E +31%, 2028E +18%의 고성장을 지속함 `[전망: LS증권 8월]`.
  - **NVIDIA 차세대 AI 시스템의 CPU 메모리 급증**:
    - Vera Rubin NVL72 시스템은 GB200 NVL72 대비 HBM 용량이 13.4TB에서 20.7TB로 +54% 증가하는 반면, CPU-side Memory는 17TB에서 54TB로 +218%(3.2배) 폭증함 `[팩트: LS증권 8월]`.
    - CPU Memory / HBM 비율은 1.3배에서 2.6배로 2배 확대되어 Host DRAM의 비중이 비약적으로 증가함 `[팩트: LS증권 8월]`.
- **시장 전망**:
  - 즉각적인 연산에 사용되는 Active KV는 HBM에 보관하되, 재참조 가능성이 높은 Hot/Warm KV Cache 및 Agent State는 Local DRAM 및 CXL(Compute Express Link) 기반 확장 메모리로 오프로드하는 '메모리 계층화(Memory Tiering)'가 필수 아키텍처로 정착될 것임 `[전망/의견: LS증권 8월]`.
  - 이로 인해 CXL 컨트롤러 및 고다층 모듈 PCB 기판(티엘비 등)의 구조적 단가 상승(ASP)과 신규 시장 창출이 가속화될 전망임 `[전망: LS증권 8월]`.

### 테마 3: 메모리 반도체 공급 제약('외화내빈')과 전공정 소부장 증설 사이클의 본격화
